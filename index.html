Xteink Meteo Sleep

Погода · луна · восход на локскрине Xteink X4 / X4 Pro / X3. Собери по своему городу и скачай как sleep.bmp

Сайт открыт по HTTPS — браузер не пускает запросы из него к ридеру в домашней сети (защита mixed content). Генератор и скачивание BMP работают полностью. Чтобы ставить карточку одной кнопкой — скачай этот файл и открой его на компьютере.
Адрес — тот, что ридер показывает в режиме передачи файлов (по умолчанию уже вписан твой). Если вдруг не отвечает: удержание кнопки → ридер в File Transfer, ноут в ту же сеть; либо точка доступа InkMOD-Reader → http://192.168.4.1.
Источники данных и обозначения
  • Погода, восход и закат — Open-Meteo.com, открытый API без регистрации
  • Город — геокодер Open-Meteo
  • Фаза Луны — астрорасчёт по дате (цикл 29,5 сут)
  • В прогнозе: д — днём, н — ночью, °C
  • Карточка обновляется, когда ты генерируешь и закидываешь новый sleep.bmp
Как поставить на устройство
  1. Скачай sleep.bmp кнопкой выше.
  2. Закинь файл в папку Sleep на microSD — перезапиши тот, что там лежит (у inkMOD заставка берётся оттуда).
  3. Режим экрана сна — «Своя картинка» (если ставил через кнопку сайта, он уже выставлен сам).
  4. Заблокировал — карточка на экране. Нужна свежая — сгенерируй и закинь заново.
