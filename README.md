# Xteink Meteo Sleep 🌙

Погода, фаза Луны и восход/закат на экране сна ридеров **Xteink X4 / X4 Pro / X3** (прошивки **inkMOD** и **CrossPoint**).

Генератор картинки для локскрина: выбрал город → `sleep.bmp` под свой экран → закинул на ридер (или отправил одной кнопкой с компа).

Выбираешь город — сайт собирает из виджетов чёрно-белую карточку ровно под экран ридера: погода сейчас, прогноз, восход/закат, фаза Луны, дата.

## Что на карточке

- День недели и дата
- Текущая температура + описание и иконка, «днём / ночью»
- **Восход** и **закат**
- **Фаза Луны** — название и % освещённости (чистый астрорасчёт по дате)
- Прогноз на 2–5 дней: `д +19° · н +15°` (д — днём, н — ночью)
- Город и время обновления

Чистый 1-битный BMP (ровно 2 цвета) — идеально для e-ink, ничего не размазывается.

## Как пользоваться

### Онлайн (генератор + скачивание)
Открыл сайт → выбрал город (запоминается) → **«Скачать sleep.bmp»** → файл в папку `Sleep` на microSD (перезаписать тот, что там лежит) → режим экрана сна «Своя картинка».

### С компьютера (полная версия, с установкой в один клик)
Скачай `index.html` из репозитория и открой его на ноуте. Появится кнопка **«Обновить и установить на ридер»**:

1. Ридер — в режим передачи файлов (у inkMOD это удержание кнопки питания, сервер поднимается за ~20 секунд)
2. Ноут — в ту же Wi-Fi сеть (или в точку доступа ридера `InkMOD-Reader`, адрес тогда `http://192.168.4.1`)
3. Адрес ридера — тот, что он показывает на экране (по умолчанию подставлен свой)
4. Кнопка → картинка летит на ридер и режим «Своя картинка» выставляется сам

> Почему кнопка не работает на онлайн-версии: сайт по HTTPS, а ридер в домашней сети — по HTTP. Браузер блокирует такие запросы (mixed content), это защита, отключить её нельзя. Локальный файл — полноценный.

## Технически

- Один файл `index.html`, чистый JS+canvas, без библиотек и сборки
- Погода, прогноз, восход/закат — [Open-Meteo](https://open-meteo.com/) (открытый API, без регистрации); город — их геокодер
- Фаза Луны — синодический цикл 29,53 суток от опорного новолуния 06.01.2000
- BMP собирается вручную в JS: 24 бита, bottom-up, порог яркости 140 → ровно 2 цвета
- Установка: `POST /upload?path=/Sleep` (multipart, поле `file`) + `POST /api/settings` `{"sleepScreen":3}` — индекс 3 = «Своя картинка» в inkMOD 1.1.x

## Совместимость

Проверено на Xteink X4 + inkMOD 1.1.7. CrossPoint (стоковые режимы сна `/sleep.bmp` в корне) и X3 — поддерживаются размерами и ручным способом; фидбек приветствуется.
